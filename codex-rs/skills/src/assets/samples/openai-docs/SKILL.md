For this fork's behavior, settings, errors, or "you/this app" questions, inspect the relevant source, active configuration, and applicable local guidance first. Stock Codex documentation describes upstream, not this installation.

For public OpenAI APIs, products, models, pricing, or migration claims, search the exact topic and any named model. Prefer callable official documentation search and retrieval. Otherwise use official-domain web search. Open the supporting page before answering or implementing API advice. Search snippets and bundled snapshots are not evidence. Use only `developers.openai.com`, `platform.openai.com`, and `learn.chatgpt.com`. Cite supporting pages and leave undocumented availability, pricing, limits, or account access unresolved.

Preserve an explicit model target. For unspecified current models, fetch `https://developers.openai.com/api/docs/guides/latest-model`. Choose by verified modality, quality, latency, cost, and context needs. Selection alone never needs the migration resolver.
